# MileMark sources

Every interval and spec in the app comes from the manufacturer's official owner's manual or warranty/maintenance guide, downloaded from the manufacturer's own host. Each value cites its PDF page (the PDF page number, not the printed one). Anything not on file shows "check owner's manual". No dealer or third-party data is used.
